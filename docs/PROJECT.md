# 项目定位与商业约束
版本：v0.1｜2026-10-11｜状态：试运行。

## 用户已明确的要求
- 账号名“地球人日志”，多平台发布，首要目的是挣钱。
- 依据实时热点，从观察者角度记录地球人历史。
- 客观呈现事实，允许明确标注的个人观察；表达幽默风趣。
- 结尾使用文明指数，有基准和公开的初版评分标准。
- 项目文件必须支持 Codex、Claude、多个新会话持续接续。

## 经营命题
热点带来首次注意；解释带来价值；稳定的语气带来辨识；证据和跟进带来信任；匹配受众的商品或服务产生收入。
不把一篇爆款、粉丝总量或评论争吵直接当作商业模式成立。

## 试运行假设（不是用户已确认的细节）
- 先服务关心科技与公共生活、希望节省理解成本的中文读者，不先锁死年龄和性别。
- 初始内容集中在科技如何进入生活、商业承诺如何兑现、社会如何解决共同问题。
- 起步采用少量渠道验证，不同时为所有平台制作独立内容。
- 品牌合作、平台收益、适配的推荐佣金为候选收入；付费产品须有实际需求。
- 2026-10-14调整：先试轻量热点切片，每天2条、连续7天为编辑建议，尚非用户确认的硬配额；按工时和实际表现调整。替代早期每周四篇加周报建议。
- 不设虚构的行业平均报价、播放收益或涨粉保证。

## 商业评价
按平台、栏目和内容形态分别比较：
- 阅读/播放、完读/完播、分享、收藏；记录平台字段原名与统计窗口。
- 每千次阅读/播放净增关注 = 可归因新增关注 / 对应阅读播放 × 1000；无法归因时标不可得。
- 回访、有效询盘、成交、实收、退款、制作工时、直接成本。
- 现金结余与包含本人劳动成本的经营利润分别展示。
- 每周查看中位表现和样本量，记录爆款但不以单个异常值决定方向。
- 顺序发布时间的标题试验属于观察性比较，不能假称随机 A/B 实验。

## 商业隔离
合作关系需要披露；不得出售文明分、收钱删除事实或接受压制正常报道的条件。
正在评议的事件中不植入涉事品牌或直接竞品广告。推荐须有可核对依据。
注册、商业化门槛、新闻信息及专业领域发布要求按所在地和平台现行规则检查，不能靠改名“观察”绕过要求。
平台优先级、预算、本人出镜与否、可投入时间、目标净利润目前未定，不阻止完成文档或试稿。

## 阶段验收
2026-10-14当前优先：先完成小批量切片与账号收益入口验证，下列早期栏目扩展验收不作为前置任务。播放量不直接计收入，未开通收益项目的分成收入不能臆测。
1. 规范可读、模板可用、共享状态可恢复。
2. 三个栏目各完成至少两份样稿，核查能通过，风格可辨识。
3. 小规模发布后形成真实数据，再选择主平台和持续栏目。
4. 出现真实商业需求并验证交付利润后，决定是否扩大投入。

## 轻量切片的商业试验（2026-10-14）
用户要求现阶段靠新闻切片提高产量、赚钱。“刷量”暂按多产作品获取真实观看理解，用户未明确要求购买虚假播放或互动；不要记录成已确认的造假意图。
先核对拟用抖音账号：粉丝数、可用变现入口、实际加入状态、对应内容/时长/原创条件。没有后台信息时继续选题和制作，但不声称已具备收益资格，也不采用第三方教程里的固定粉丝门槛。
用户补充：所有账号均为零粉初始阶段。粉丝数已知，不再询问；先把首批作品作为内容验证，分成收入按未验证处理，不作为投入预算依据。零粉不自动意味着任何收益渠道都不可用。
起步建议抖音主测，先完成同一方向3条（科技演示或产品实际变化），统一30秒左右结构，测试“关键动作开头、前后对比开头、具体问题开头”三种写法。不同事件之间存在混杂，不作为严格A/B试验。小红书在母版稳定且素材使用范围适配后复用，不同时建立多个独立生产流程。
第一阶段区分两个结果：内容是否获得真实观看、账号是否产生可结算收入。未开通变现时是验证内容，不承诺发片立即挣钱。
试验建议：每天2条，7天最多14条；单条25–45秒为初始编辑选择，若账号确认的收益计划有其他时长/内容要求再调整，不硬凑一分钟。不因缺乏可靠素材凑数。
制作工时目标：素材到齐后每条约30分钟，这是待测目标，不含事实核查和素材获取，不保证总工时。前3条记录实际总时长后决定是否可扩量。
每条记录发布时间、视频时长、制作总分钟、24/72小时播放/平均观看时长/完播/可归因新增关注、收益计划资格、预计与已结算收益、直接成本。无字段填不可得，没开通不能用行业单价乘播放量。
第3条检查工时，第7天比较同长度作品的中位表现、总工时和实收；少量样本只用于筛选方向，不证明算法偏好。无可用变现入口时先决定是否继续获客/涨粉试验，不靠提高产量掩盖收益缺口。
不自动购买素材、会员或流量，不创建自动定时发布；用户操作发布，AI负责材料与记录。
