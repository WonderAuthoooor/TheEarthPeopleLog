# 地球文明观察指数
规则版本：v0.1｜基准：1000.0｜2026-10-11。
这是“已收录事件的编辑性观察账本”，不是科学测量、全球随机抽样或国家民族排名。

## 维度与公式
生命福祉 life、尊严权利 rights、知识求真 knowledge、协作治理 cooperation、长期可持续 sustainability。
每维度取 -2、-1、0、1、2；+/-1 表示有限明确改善/损害；+/-2 表示重大或持久改善/损害。
只评与事件相关的维度，其他记0；证据不足以作总判断时整个事件待评，score 为 null。
已确认的部分可单独限定评估范围，不把未知影响猜成零。
事件总分 = 五维之和 × 0.5，范围 -5.0 至 +5.0。
同一后果只计一次；跨维度必须说明独立的后果链。
影响人数、强度、持续性、可逆性、预防与补救责任支撑严重程度，热搜排名不支撑分数。

## 三种输出
- scored：有充分依据，显示分项与总分（允许0）。
- pending：信息不足，不进入累计分。
- excluded：不适用或重复事件，记录理由，不进入累计分。
不因“这一篇结尾需要扣分”逆推事实。

## 边界
自然事件本身不扣文明分；评估可归责的人类行为及响应。
口号、命名、宣布目标一般不能当作已兑现效果，按实际可证实影响评估。
整改先调整原事件损害；避免“制造问题再修复”净赚分。真正独立且超出补救的制度收益须另列证据与范围。
同一事件更新用同一 event_id，不能换标题重复计分。
关联事件检查重叠后果，说明如何避免重复计算。
每月审视入选偏差：漏掉了什么、有无只搜负面；不通过人为加正分“平衡”账本。

## 权威数据
state/score-ledger.json 是唯一累计数据源；文稿内数字是带日期与版本的展示快照。
初始 entries=[]，baseline=1000.0。未发布的样稿与训练示例不入账。
每个账本条目是事件修订，至少包含：
entry_id（唯一）、event_id、revision（从1连续递增）、supersedes（首版null，否则前一entry_id）、
status、dimensions、score、previous_score、delta、reason、source_refs、rule_version、
story_path、effective_at（ISO 8601带时区）、recorded_by、publication_refs。
scored 的 dimensions 为五个整数；pending/excluded 时 dimensions 和 score 为 null。
previous_score 是该事件上一修订对累计数的有效贡献，首版为0；
有效贡献 = scored 时 score，否则0；delta = 本修订有效贡献 - previous_score。
例如 -1.5 修订为 -0.5，delta=+1.0；撤回原 -1.5 评分改待评，delta=+1.5，必须解释撤回依据。
当前总数 = baseline + 所有修订的 delta 之和；也应等于 baseline + 每个事件最新有效贡献之和。
不直接手改累计值、不删除旧条目；错账通过新增修订纠正。
事件修订和总账写入由持锁者串行完成，同次更新对应稿件及平台更正状态。

## 示范口径（虚构，不入账）
仅更名，未确认实质改善：可评0，限定“名称替换本身”。
已确认的有限安全缺陷：life=-1，其余0，总分-0.5；更严重情形据证据提高幅度。
安全争议尚待核查：pending，不能提前写“必扣分”。
避免模板抢先决定真实案件：这些是尺度演示，不是对用户举例的事实结论。

## 版本变更
分值算法、基准、入账范围变更必须新增决策记录，保留旧规则版本或完整变更说明。
默认新规则向前适用；需要回算时列出受影响事件及迁移表，不静默改历史。
