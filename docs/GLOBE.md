# 独立地点动画应用
版本：EarthPeopleLogGlobe 0.2.0｜更新：2026-10-20T23:06:55+08:00。

## 当前交付与边界
用户要求地点动画与虚拟主播独立开发，导出后在剪映组合。本版只负责城市搜索、详细显示地点、地球开场／转场和可替换开场大手，输出干净MP4；无人物叠加、角色模型或评分输入，不需要安装／启动工作室或虚拟主播程序。角色制作的唯一规范见[AVATAR](AVATAR.md)。

工作室0.3.1是此前合并版本，旧EXE与旧输出保留，内部角色界面不会因源码变化自动升级。请用根目录新快捷方式「地球地点动画.lnk」，不要用旧工坊制作新地点素材。当前独立EXE为dist/globe/0.2.0/EarthPeopleLogGlobe/EarthPeopleLogGlobe.exe，安装包为dist/EarthPeopleLogGlobe-0.2.0-Setup.exe。目录版须保持整个文件夹完整；日常无需CMD、Python、Codex或外部服务。

## 最短使用步骤
1. 双击根目录「地球地点动画」，选择「复古夸张」或「原版·平稳地球」，再选「开场」或「资讯间·地点转场」。
2. 在「附近城市」输入中文／英文城市或国家地区，从搜索结果选择。转场同时选择出发城市；开场可从默认地球观察站开始。库内1,252城市是区域覆盖与常用地点，不是实时热榜。
3. 「动画显示地点」可单独填详细名称，例如附近城市选名古屋，文字写「日本·爱知县丰田市某工厂」。详细文字不改变落点，无需查询或填写经纬度；所有画面文字默认关闭；需显示时，在下方「画面文字」勾选「详细地点名称」或「附近城市／位置示意」。
4. 开场可显示／关闭大手，或导入SVG／透明PNG替换。普通转场不加载手部素材。大手是转场道具，不绑定虚拟主播；以后可按美术与剪辑需要呼应。
5. 默认不生成任何文字。栏目名称、英文副标题、过程提示语、详细地点名称、附近城市／位置示意、底部栏目说明六项独立勾选；只显示选中的文字。
6. 选择时长和1080p／540p，点击生成。生成成功后打开目录，将MP4拖到剪映的开场或新闻之间。输出静音，角色、新闻音轨和音乐在剪映单独组合。

复古风格默认开场3秒、转场1.4秒；原版默认开场5秒、转场3秒。是工程初值，不是必须时长；切换风格／类型会更新默认时长，已保存的自定义时长重开保留。先用540p看节奏，再按需要生成1080p。程序展示导出末帧缩略图，不是完整动画实时预览。最近一次开始生成的有效设置会原子保存，重开恢复城市、详细文字、时长、尺寸、开场大手和用户自己勾选的文字开关；旧0.1.0设置未记录文字开关时全部按关闭处理；生成后的组件副本可复现该次输出。界面升级旧偏好时默认启用复古风格，原内置外星手默认改为复古白手套，已选自定义素材保留；内置组件路径自动适配新版本目录。

## 工作区与旧资料
根目录快捷方式显式使用.globe，包含preferences.json、animation-runs/UUID和animations/日期_类型_UUID；与.studio／.pipeline分开，不建立工作室SQLite、不改新闻工程或文明账本。直接双击EXE／安装版的默认工作区为用户Documents/地球地点动画，和根目录快捷方式不同。输出各自唯一，不覆盖已有视频。

可从content/digests/日期/stories.json导入地点，每条location可提供name（详细显示文字）和city（附近城市名）；带旧lat/lon的资讯地点会匹配已收录城市中球面距离最近者，保留原显示文字。未知／重名城市不猜国家首都，提示手动选择；研究机构、比赛与报道地点须分清。

旧动画settings／request中若含mascot、show_mascot或score等字段，或mode=mascot，新引擎会明确报错并提示重新选择城市，不静默去掉角色或改写旧工程。旧MP4／MOV仍可使用，旧程序目录保留；兼容的资讯地点导入与旧动画任务是两种不同输入。

## 代码、构建与契约
- globe_entry.py：独立GUI／worker／自检入口；globe_app/为独立UI与0.2.0版本，拥有自己的图标、Windows应用身份与资源目录。
- pipeline/globe_motion.py：无渲染依赖的相机／形变时间线；pipeline/globe_retro.py：原创墨线／复古配色／手套／残影皮肤；
- pipeline/globe.py：纯地点引擎；pipeline/cities.py：离线检索／导入匹配；pipeline/processes.py：共享媒体子进程保护。少量媒体基础工具可复用源码，各应用自行打包，不互相依赖运行。
- studio/animation_dialog.py与studio/processes.py仅为源码兼容导入；新地点安装包明确排除studio、旧mascots与下载器，不带角色SDK。
- scripts/build-globe.py生成独立onedir、许可证和源码／资产构建哈希；scripts/build-installer.py --app globe生成独立安装器、注册表身份和快捷方式，不覆盖工作室。scripts/create-globe-shortcut.ps1更新项目内独立入口。
- settings schema_version=2，style=rubberhose/classic，mode=intro/transition，origin/target含name、lat、lon；target含city_name、city_id、precision。坐标是内部渲染数据，GUI从城市库读取；无mascot或score字段。旧任务缺少style时按classic解释，保持历史渲染语义；新GUI明确保存所选风格。
- width=540/1080为UI选项，height按9:16推导，fps=30、duration=1—20秒；show_hand仅影响开场，hand为本地SVG／PNG。转场与无大手开场不验证／复制手素材。
- text_options为六个布尔开关：title／subtitle／status／location／nearby／footer，缺省全部false；无效字段或非布尔值在渲染前报错。定位标记不属于文字开关，始终保留原有定位行为。
- request含config、output_root、progress_file、result_file、cancel_file；独立QProcess编码，进度可见、可取消。Windows Job Object仅约束本次媒体子进程。
- 每个输出含MP4、首尾PNG、settings.json、manifest.json、encoder.log和本次实际使用的components。先写.part，成功原子更名；失败／取消保留原因并移除半成品。

陆地与城市来自Natural Earth；来源及原文件SHA256见pipeline/assets/NOTICE.md与locations-source.json。打包不绘制行政边界，低比例尺定位不提供导航或测绘精度；不承诺覆盖所有城市或详细地址自动地理编码。

## 0.2.0复古夸张风格首版
用户已同意继续实施此前镜头建议。当前原创橡皮管动画皮肤采用暖纸色背景、蓝绿海洋／赭黄陆地、粗墨线和白手套；地球接触时挤压／回弹，快速旋转有残影与动势线，背景保持稳定。不引入人物、强制文字或固定城市预渲染。

开场：短暂蓄力／反向倾斜 → 手套拨动与横向挤压 → 约三圈衰减旋转、形变回弹／残影 → 转向目标同时推近 → 末段正常比例与稳定定位。日常转场：上一地点近景 → 退到全景 → 转向并同时靠近下一地点 → 稳定定位。画面末段约9%固定，3秒开场约0.27秒；最终放大至基础球体2.25倍，比旧版仅约12%的缩放明显。

同一风格且文字关闭时，上一段开场／转场最后一帧可与下一转场第一帧对齐（下一段origin设为上一target）。跨日期变更线走短向；定位标记出现前形变／倾斜已收敛，最终落点按附近城市示意。可选择原版平稳地球作比较或用于不适合夸张包装的题材。

首版仍为静音，不加胶片颗粒，也未开发音效／颗粒开关；这些不是已交付能力。镜头在低比例尺球面地图上拉近，不提供街道细节。新闻钩子、整期只用一次完整开场属于剪辑建议，不自动替用户拼接新闻。虚拟主播C继续独立制作。
