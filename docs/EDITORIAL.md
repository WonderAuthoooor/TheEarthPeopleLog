# 编辑与发布规范
版本：v0.1｜2026-10-11。

## 证据单位
每篇建立独立事件档案，使用 templates/STORY.md。主张编号 C01 等，来源编号 S01 等。
来源保存标题、主体、原始URL、发布日期、访问时间、支持的主张及局限。搜索摘要只是线索。
原始文件优先；机构声明只证明其作出声明，不能单独证明全部技术主张。原视频需核查时间、剪辑、条件和上下文。
多家转载同一源不算独立交叉验证。专业结论优先原始研究、监管或检测文件，不让模型补技术判决。
历史聊天中的链接和断言必须重新打开核对；无法访问写明限制，不升级为已核实。
“截至”时间写在事实卡和成稿，发布前复核关键进展；排期跨日或重大进展必须再次检查。

## 明确区分
事实：证据支持的发生情况。
说法：某人/机构明确提出的主张，保留归属。
推断：由事实推得的解释，写明逻辑和替代解释。
评论：编辑的价值判断，单独标记。
示例/演绎：明确标记，永远不是来源。
客观不要求给无证据说法同等篇幅；不同主体适用同一证据标准。

## 状态流转
idea → researching → drafting → review → ready → published → updated / withdrawn。
ready 表示稿件达到发布标准，不代表已获账号操作授权，也不代表已经发布。
缺少证据时回 researching；有问题记录检查项而不是绕过。
发布时必须同时具备：核查通过、素材使用依据、平台条件满足、相应用户授权、发布回执。
授权按用户实际范围保存，可覆盖一批稿件；已有授权不重复询问。
同一模型分两轮核查只能叫二次检查，不能称独立复核。重大争议由有能力的人工负责最终编辑判断。

## 素材和 AI
引用、配图和视频各自记录使用依据；标注来源不自动等于获得版权许可。
不下载搬运整段他人内容再用旁白包装成原创，不生成冒充现场的图像或声音。
AI生成合成内容按实际使用情况、现行规定及平台功能声明和标识；保留原始标识。
记录哪些部分由AI辅助、哪些证据由人核对；不把所有文字编辑一律等同于同一种标识要求。
不用未获授权的真人克隆声音或伪造发言。

新闻视频摘录保留原出处、日期、原视频时码和必要上下文；转录时间只作找片线索，拿到视频后核对实际时码。短于若干秒不自动等于可以任意使用。来源、使用依据与素材是否已取得分别记录，不以“找到了网页”代替已下载/已看原片。
网友评论仅证明某用户表达过某意见，不作为事件事实或整体舆论的证据；执行CONTENT第12节的真实评论规则。

## 发布前清单
- [ ] 主体、日期、数字、单位、引语、适用范围逐一核对。
- [ ] 争议各方说法归属清楚，重要反证和未知项未省略。
- [ ] 标题封面和笑点没有制造新增事实。
- [ ] 素材使用依据和AI标识已处理。
- [ ] 评分复算通过；待评不计零分，不重复记账。
- [ ] 商业关系已披露，符合所在平台当前账号和内容要求。
- [ ] 来源、截止时间、稿件版本完整。
- [ ] 用户授权范围覆盖本次外部发布；不得从“做方案”推断为“立即发布”。

## 发布与更正
保存各平台链接/内容ID、实际发布时间、版本号、发布回执、授权依据。
重大事实错误：先暂停未发版本，及时在已发渠道显著更正；必要时撤下并说明原因，不抹去内部记录。
更正记载旧表述、新表述、证据、发现及处理时间、受影响的平台和评分差额。
编辑未发送的草稿可以正常改，不必制造公开更正。
评论区接受质疑与证据，不组织围攻，不通过删除合理质疑维持表面一致。
